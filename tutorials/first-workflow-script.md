Starting with an empty canvas:

"This is Coda - a data analysis tool for neuroscience. It is designed to help you explore and analyze data in a visual and interactive way."

## The dataset

"Every workflow in Coda starts with a dataset node. To add nodes click the + button, open a category and select a node."

> Mouse moves to + button, clicks, opens the "Dataset" catgory"

"You can also search for nodes by name."

> Mouse moves to 'Browse all nodes` button and clicks it.

"Let's add a dataset node for the Male CNS - the connectome of a fruit fly's central nervous system.

> Cursor types "Male" to the search bar, mouse clicks on 'Male CNS (neuPrint)' node which adds it to the canvas.

"Next we need something to explore the dataset. There are multiple ways to find neurons of interest but let's start with the "Explore Dataset" node.

> Mouse clicks on the + button, opens the "Query nodes" category and clicks on the "Explore Dataset" node.

"Coda wired the new node to the dataset for you. Drag it by its header to wherever you like."

> Mouse drags the "Explore Dataset" node to the right of the dataset node.

"Many nodes can be expanded to show additional information."

> Mouse clicks on the "Open result in full size" button of the "Explore Dataset" node.

"Let's look for a specific neuron. You can use free-form fuzzy searches or search by specific fields."

> Cursor types "type==CT1" to the search bar, mouse clicks hovers over the thumbnail of the first result to show the neuron in 3D.

"To select neurons, tick the checkbox or use the controls in the bottom right corner."

> Mouse clicks on "+All" button to select all neurons in the result. Then mouse clicks on the "Close" button to close the full-size view.

"Next, we will visualize the neurons in 3D by adding a "Neuroglancer" node. Note you can also add nodes by dragging a wire and dropping it on the canvas."

> Mouse drags a wire from the "Explore Dataset" node to an empty space on the canvas. A menu appears, cursors enters "Neuroglancer" to the search bar and clicks on the "Neuroglancer" node.

"Let's say we want to know more about the neurons we selected. One easy way to do this is to use the "Neuron Profile" node. It gives you a high-level summary of the neurons you selected.

> Mouse drags a wire from the "Explore Dataset" node to the empty space below the "Neuroglancer" node. A menu appears, cursors enters "Neuron Profile" to the search bar and clicks on the "Neuron Profile" node.

"Once you built your workflow you can turn it into a Dashboard. Dashboards let you focus on the most relevant parts of a workflow."

> Mouse clicks on the "Dashboard" button in the top right corner of the UI. Then it clicks on '+ Add node' and selects the "Neuron Profile" node. It then resizes the node to full height. Then it clicks on '+ Add node' and selects the "Neuroglancer" node. It then resizes the node to full height.

"Workflows, including dashboard views, can be shared with others using a simple link."

> Mouse clicks on the 'Share workflow' button in the top bar. Then moves to and hovers over the 'Copy' button of the 'Share workflow' dialog for 2s. Then it clicks on the 'Close' button of the dialog. Then clicks the 'Back to the canvas' button to go back to the workflow.

"You learned the basics of building a workflow in Coda but we've barely scratched the surface. There are many more nodes to explore."

"Make sure to check out the 'Workflow Wizard' - it helps you build workflows for common tasks by asking a series of simple questions."

> Mouse clicks on "New" -> "Workflow Wizard". Then it clicks through the questions, selecting: 'MaleCNS (neuPrint)' -> 'Interactive Search with Thumbnails' -> 'Shortest Paths' -> 'Continue' -> 'Create workflow'.

"If you get stuck, you can always check out the documentation or reach out to us for help."

> Mouse clicks in the "?" help button in the top bar. Then hovers over 'Guides' and 'Documentation' submenus for 1s each.
