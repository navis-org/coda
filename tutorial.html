Chapter 1

A node is one step

Every step is a card. Find Neurons runs one query: match a type pattern against a dataset. Here, traced lobula columnar cells — ^LC\d+$.

Four regions, the same on every card. Inputs left, outputs right, parameters between them, the last result along the bottom. ▶ in the header runs this node and whatever it depends on, nothing else.

The stripe down the left edge is run state. Grey here: the Dataset input is empty, so there is nothing to run yet.

Chapter 2

Sockets are typed

A link carries a typed value, not a file. Each socket declares what it accepts, so a link that cannot work is refused as you drag it — with the reason, at edit time.

Dataset — a connectome at a version
Neurons — a table guaranteed to carry bodyId
Table — any rows and columns
Matrix — rows × columns of numbers

Colour, shape and label — three channels. Only three hues clear an all-pairs colourblind check when any two may sit adjacent, so shape carries the rest.

Types also carry their column schema. Connectivity Graph publishes preType, postType, weight and the rest the moment it is wired, so every column dropdown downstream is populated before a row is fetched.

Chapter 3

Execution model

Cost is declared per node. Cheap ones — Filter, Sort, Group By — re-run about 180 ms after you stop editing. Expensive ones hit a backend and go stale instead: a reactive editor pointed at a shared production Neo4j would fire a query per keystroke.

Run (⇧R) executes everything stale, in dependency order. ▶ on a card executes that node and only its upstream. Both report progress as a gold ring round the card.

Auto-run opts out of the split entirely: every edit re-runs the whole graph, expensive nodes included, debounced so a burst of edits sends one query. Off by default and remembered, so an expensive workflow stays on manual.

Freshness is a provenance key — hash(type, params, upstream keys) — not a comparison of data. Undo an edit and the old cached results are valid again, with no re-query.

Chapter 5

Viewers are interactive

Bar Chart draws the table and passes the same table on, so a viewer drops into the middle of a chain without breaking it. Table, Heatmap, Scatter Plot, Network Viewer, 3D Viewer and an embedded neuroglancer all behave this way.

Several also emit a selection. Lasso points in Scatter Plot, click nodes in Network Viewer: the picked rows leave by a Selected output and wire onward like anything else.

Chapter 6

Save it, send it

The graph is the method: every step, every parameter, the exact dataset version. Save ▸ Download writes it as a .coda.json — plain JSON, so it belongs in a repository or a supplement.

Results are not in the file; it stores the recipe. Whoever opens it gets this pipeline exactly as you left it, presses Run, and can move a threshold to see what changes.

Chapter 7

Browsing a connectome

Find Neurons needs a pattern up front. Explore Dataset does not.

Explore Dataset enables fuzzy search

The dataset’s whole neuron table is downloaded once and searched locally — male‑CNS is 165,122 traced cells × 20 properties, ~7 MB gzipped, about five seconds, after which a scan costs ~6 ms and the server nothing. Bare terms match any field; !x excludes, class==sensory compares, post>1000 is numeric, type~^LC[0-9]+$ is a regex. Terms are ANDed. A query with no hits retries as a subsequence match and says so.

Select neurons of interest and they flow downstream

Three outputs. Hits is everything matching the query, Selected only the ticked rows, and All the index untouched — the whole neuron‑by‑property table, ready for a Group By or a chart with no second query.

Neuron Profile provides neuron-level summaries

Identity, transmitter, synapse totals, strongest partners, the per‑ROI split and the morphology — one neuron at a time. Page through a collection freely; pin one and it leaves by Current.

Chapter 8

Point it at a real connectome

Coda ships with a synthetic connectome generated in the browser, so every example runs with no account and no network. Real data takes one more step.

Paste a token once

Sign in at neuprint.janelia.org and copy your auth token from the account menu. In Coda: Sources in the toolbar, paste, Test.

It stays in this browser

Held in local storage, never written into a saved workflow — so a .coda.json you send a colleague carries the analysis and not your credentials.

One node per dataset

No backend to choose. Add ▸ Dataset ▸ Hemibrain arrives pointed somewhere and asks only for a version, defaulting to the newest release the server reports — named in full, so a shared workflow never leaves anyone guessing which one it used.

Credit comes attached

Every published dataset node arrives with a Description card wired to it: what the dataset covers and the papers its authors ask you to cite, as neuPrint publishes it. An ordinary node — delete it if you would rather not have it.

Chapter 9

Getting around the canvas

Two keys do almost everything: Space for commands and nodes by name, Tab for the browser.

Initials work in the palette: ra → Run All, gb → Group By.

Drag pans. Panning is the common gesture, so it is the bare one.
⇧ + drag draws a selection box.
Scroll zooms. Double‑click empty canvas adds a node there.
Drag a wire into empty space for a list filtered to what accepts it — your pick arrives wired.
Drag either end of a wire off its socket to re-route; right‑click it for a menu. A drop on a socket that refuses snaps back rather than cutting the link.
The corner controls auto-arrange the graph left to right, once or continuously.
Chapter 10

Where a workflow goes

Two places, and only one of them is durable.

Save ▸ Download · durable

A .coda.json file

The real artefact. Plain JSON — it goes in a repository, a supplement, an email, and reproduces the pipeline wherever it lands. Results are not in it: the recipe, not the meal.

Save ▸ In this browser · convenient

The browser shelf

A named copy on this machine, listed under Open and on the start page. Good for picking up where you left off.

Not a backup. Per browser and per profile, not synced, empty in a private window, and cleared with the site data. Anything you would be sorry to lose, download.

Data comes out separately: any viewer exports what it is showing — CSV from a table, SVG or PNG from a chart — and a Download node at the end of a chain writes its file on every run, so a pipeline re‑run tomorrow refreshes its own outputs.

Open it and add one node.

Nothing to install, and the bundled examples run with no account. Start from one, take it apart, point it at your own question.
